# KenshiRevive

⚠️ **NOTE:** I made this mod for my girlfriend, I hate C++, I hate Windows and I'm not changing or maintaining this unless she wants a change.

Add a revive button that fully heals ANY dead character and puts them in your squad.

![Screenshot of the mod](_KenshiRevive.img)

## Requirements

- [RE_Kenshi](https://github.com/BFrizzleFoShizzle/RE_Kenshi) ([Nexus](https://www.nexusmods.com/kenshi/mods/847)) — includes KenshiLib

## Installation

1. Download the latest release
2. Copy the `KenshiRevive` folder into Kenshi's `mods\` directory
3. Launch Kenshi via the RE_Kenshi launcher
